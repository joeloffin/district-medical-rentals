# District Medical Rentals

Website for District Medical Rentals — medical-grade lift chairs and electronic medical beds delivered across Washington, DC, Maryland, and Virginia.

## Open locally

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 5173
```

Then visit [http://localhost:5173](http://localhost:5173).

## Contact

Phone on site: **917-346-5309**

Rental requests from the contact form are saved in the visitor’s browser (`localStorage` key `dmr-rental-requests`) and shown as a confirmation on the page. Connect a form backend (Formspree, Netlify Forms, etc.) when you’re ready to receive inquiries by email.
